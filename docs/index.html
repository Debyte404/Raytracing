Core Mathematics

The essential formulas powering every ray tracing operation

r(t) = o + t·d

Ray Equation

A ray defined by origin point o, direction vector d, and parameter t along the line.

|p - c|² = r²

Sphere Equation

All points p at distance r from center c form the sphere surface.

I = N · L

Lambertian Shading

Intensity is the dot product of surface normal N and light direction L.

R = D - 2(D·N)N

Reflection Vector

Reflect direction D about normal N using vector projection.
