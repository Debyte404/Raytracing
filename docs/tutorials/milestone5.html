📐 Core Concepts

1. Axis-Aligned Plane Intersection

Walls are infinite planes. For axis-aligned planes (like room walls), intersection is trivial:

For plane x = k: t = (k - origin.x) / direction.x
For plane y = k: t = (k - origin.y) / direction.y
For plane z = k: t = (k - origin.z) / direction.z

💡 Why Planes for Walls?

Instead of modeling walls as giant boxes, we use mathematical planes. They're simpler to intersect, use less memory, and render faster. We just need to check that the hit point is within the wall's bounds.

2. Emissive Materials (Light Sources)

An emissive material doesn't reflect light — it emits it. When a ray hits an emissive surface, we immediately return its emission color, regardless of bounce depth.

if (material.emission > 0)
  return material.emissionColor;

3. Color Bleeding (Indirect Illumination)

When light bounces off a colored wall, it picks up that wall's color. This is why the white floor near the red wall looks slightly pink.

🌈 How Color Bleeding Works

1. Light ray hits red wall → reflects with red tint
2. Reflected ray hits white floor → floor appears red-tinted
3. This happens with every bounce, creating soft color gradients
4. More bounces = more accurate but slower

4. Soft Shadows

Real light sources have area, not just a point. In our ray tracer, we approximate this by checking if a point can "see" the light source. If the path to the light is blocked, the point is in shadow.

Shadow Ray: from hit point toward light
If shadow ray hits anything before reaching light → shadow
If shadow ray reaches light → illuminated

// Full trace with emission support
float3 TraceRay(Ray ray, int depth)
{
    if (depth >= MAX_BOUNCES)
        return float3(0, 0, 0);
    
    RayHit hit = CreateRayHit();
    
    // Test spheres
    for (int i = 0; i < _SphereCount; i++)
        IntersectSphere(ray, _Spheres[i], hit);
    
    // If no sphere hit, check walls (simplified as bounds check)
    if (hit.distance >= 1.#INF)
    {
        // Simple wall intersection (for demonstration)
        // In production, use proper plane intersection
        return float3(0.05f, 0.05f, 0.05f);  // Dark void
    }
    
    // If emissive, return emission immediately
    if (length(hit.emission) > 0.01f)
        return hit.emission;
    
    // Local shading
    float3 localColor = Shade(hit);
    
    // Reflection
    if (length(hit.specular) > 0.01f && depth < MAX_BOUNCES - 1)
    {
        Ray reflectedRay;
        reflectedRay.origin = hit.position + hit.normal * 0.001f;
        reflectedRay.direction = Reflect(ray.direction, hit.normal);
        
        float3 reflectedColor = TraceRay(reflectedRay, depth + 1);
        localColor = lerp(localColor, reflectedColor, hit.specular);
    }
    
    return localColor;
}

Proper Plane Intersection (Production-Ready)

HLSL 
// A plane is defined by: dot(p, normal) = distance
// Or equivalently: ax + by + cz + d = 0

struct Plane
{
    float3 normal;      // Unit normal vector
    float distance;     // Signed distance from origin
    float3 albedo;
    float pad;
};

void IntersectPlane(Ray ray, Plane plane, inout RayHit bestHit,
    float2 boundsX, float2 boundsY, float2 boundsZ)
{
    // Plane: dot(p, N) = d
    // Ray: p = origin + t * direction
    // Substitute: dot(origin + t*direction, N) = d
    // dot(origin, N) + t*dot(direction, N) = d
    // t = (d - dot(origin, N)) / dot(direction, N)
    
    float denom = dot(ray.direction, plane.normal);
    
    // If denom is ~0, ray is parallel to plane
    if (abs(denom) < 0.0001f)
        return;
    
    float t = (plane.distance - dot(ray.origin, plane.normal)) / denom;
    
    // Check if hit is in front of ray and closer than current best
    if (t < 0.001f || t >= bestHit.distance)
        return;
    
    float3 hitPos = ray.origin + t * ray.direction;
    
    // Check bounds (walls have finite size)
    if (hitPos.x < boundsX.x || hitPos.x > boundsX.y ||
        hitPos.y < boundsY.x || hitPos.y > boundsY.y ||
        hitPos.z < boundsZ.x || hitPos.z > boundsZ.z)
        return;
    
    // Valid hit!
    bestHit.distance = t;
    bestHit.position = hitPos;
    bestHit.normal = plane.normal;
    bestHit.albedo = plane.albedo;
    bestHit.specular = float3(0, 0, 0);  // Walls are diffuse
}

// Cornell Box walls
Plane GetLeftWall()
{
    Plane p;
    p.normal = float3(1, 0, 0);      // Points right (into room)
    p.distance = -2.5f;                  // At x = -2.5
    p.albedo = float3(0.8f, 0.1f, 0.1f);  // Red
    return p;
}

Plane GetRightWall()
{
    Plane p;
    p.normal = float3(-1, 0, 0);     // Points left (into room)
    p.distance = -2.5f;                  // At x = 2.5, dot((2.5,0,0),(-1,0,0)) = -2.5
    p.albedo = float3(0.1f, 0.8f, 0.1f);  // Green
    return p;
}

🎯 Understanding Plane Distance

The plane equation dot(p, N) = d means: project any point p onto the normal N. If that projection equals d, the point is on the plane. For a wall at x = -2.5 with normal (1,0,0), d = -2.5 because dot((-2.5, y, z), (1,0,0)) = -2.5.

🧮 The Math Deep Dive

Why does color bleeding need multiple bounces?

Consider light hitting the red wall, then bouncing to the floor:

  1. Bounce 0: Light ray leaves the emissive sphere
  2. Bounce 1: Hits red wall → wall reflects red-tinted light
  3. Bounce 2: Red-tinted light hits white floor → floor appears pink
  4. Bounce 3: Some of that pink light hits the green wall → subtle color mixing

Each bounce adds subtlety. With only 1-2 bounces, color bleeding is barely visible. With 4-8 bounces, the scene looks natural.

Soft Shadows with Area Lights

Our emissive sphere acts as an area light. For true soft shadows, we'd cast multiple rays toward random points on the light source and average the results. For now, a single shadow ray gives hard shadows; multiple samples give soft shadows.

shadow = 0
for i = 1 to N:
  lightPoint = randomPointOnLightSource()
  if (!occluded(hit, lightPoint)):
    shadow += 1/N
color *= shadow

✅ Verification

Your Cornell Box should show:

  • Red left wall, green right wall, white everything else
  • Two spheres: one reflective (chrome), one diffuse (orange)
  • The reflective sphere mirrors the room and other sphere
  • White floor appears slightly pink near red wall (color bleeding)
  • White floor appears slightly green near green wall
  • Light source on ceiling casts shadows
  • Shadows are darker where fully occluded, lighter at edges

🐛 Common Bug

If walls appear black or missing, check your plane distance signs. The distance in dot(p, N) = d must be consistent with the normal direction. A common mistake is using positive distance when the normal points toward negative space.
