Milestone 4 — Ray Bouncing

The Mirror Dimension

Implement recursive ray bouncing to create reflections, refractions, and the foundations of global illumination.

🎯 What You'll Build

A reflective sphere that mirrors its surroundings. When a ray hits the sphere, it bounces off and samples the color from whatever it hits next. Combined with a ground plane, you'll see the sphere reflecting the floor and sky.

Interactive: Move your mouse to change the incoming ray angle. Watch the primary ray (cyan) hit the sphere, generate a reflected ray (pink), which then hits the ground plane. The reflection vector is calculated using R = D - 2(D·N)N.

📐 Core Concepts

1. The Reflection Vector

When a ray hits a surface, it bounces off at the same angle it arrived — like a mirror. The reflected direction is computed using:

R = D - 2(D · N)N

Where:

  • D = Incoming ray direction (normalized)
  • N = Surface normal at hit point (normalized)
  • R = Reflected ray direction (normalized)

💡 Intuition

Imagine throwing a ball at a wall. The component of velocity parallel to the wall stays the same, but the perpendicular component reverses. The formula does exactly this using vector projection.

2. Why This Formula Works (Vector Decomposition)

Any vector can be split into components parallel and perpendicular to a normal:

D = Dparallel + Dperpendicular
Dparallel = (D · N)N   // Component along normal
Dperpendicular = D - (D · N)N   // Component perpendicular to normal

Reflection keeps the parallel component but flips the perpendicular one:

R = Dparallel - Dperpendicular
R = (D · N)N - (D - (D · N)N)
R = 2(D · N)N - D
R = D - 2(D · N)N   (same thing, rearranged)

3. Recursive Ray Tracing

Real materials are rarely purely diffuse or purely reflective. We blend between shading modes:

1

Primary Ray

From camera through pixel

2

Hit Surface

Compute normal & reflect

3

Secondary Ray

Cast reflected ray

4

Blend

Mix local + reflected color

finalColor = localColor × (1 - reflectivity) + reflectedColor × reflectivity

💻 Implementation

HLSL Reflection & Recursive Trace

HLSL 
// Maximum recursion depth for ray bounces
#define MAX_BOUNCES 4

// Compute reflection direction
float3 Reflect(float3 direction, float3 normal)
{
    // R = D - 2(D·N)N
    return direction - 2.0f * dot(direction, normal) * normal;
}

// Trace a ray with bounces
float3 TraceRay(Ray ray, int depth)
{
    // Base case: stop recursing at max depth
    if (depth >= MAX_BOUNCES)
        return float3(0, 0, 0);  // Return black
    
    // Find closest intersection
    RayHit hit = CreateRayHit();
    
    for (int i = 0; i < _SphereCount; i++)
        IntersectSphere(ray, _Spheres[i], hit);
    
    IntersectGroundPlane(ray, hit);
    
    // If no hit, return sky color
    if (hit.distance >= 1.#INF)
    {
        // Simple sky gradient based on ray direction
        float t = 0.5f * (ray.direction.y + 1.0f);
        return lerp(float3(1, 1, 1), float3(0.5f, 0.7f, 1.0f), t);
    }
    
    // Compute local shading (diffuse)
    float3 localColor = Shade(hit);
    
    // Compute reflection
    float3 reflectivity = hit.specular;  // How reflective is this surface?
    
    // Only trace reflection if surface is somewhat reflective
    if (length(reflectivity) > 0.01f && depth < MAX_BOUNCES - 1)
    {
        // Create reflected ray
        Ray reflectedRay;
        reflectedRay.origin = hit.position + hit.normal * 0.001f;  // Offset to avoid self-intersection
        reflectedRay.direction = Reflect(ray.direction, hit.normal);
        
        // Recursively trace the reflected ray
        float3 reflectedColor = TraceRay(reflectedRay, depth + 1);
        
        // Blend local and reflected color
        localColor = lerp(localColor, reflectedColor, reflectivity);
    }
    
    return localColor;
}

// Main entry point
[numthreads(8, 8, 1)]
void MainRayGen(uint3 id : SV_DispatchThreadID)
{
    uint width, height;
    Result.GetDimensions(width, height);
    
    float2 uv = float2(id.x / (float)width, id.y / (float)height);
    
    Ray ray = CreateRay(uv);
    
    // Start tracing with bounce depth = 0
    float3 color = TraceRay(ray, 0);
    
    Result[id.xy] = float4(color, 1.0f);
}

Updated Sphere Data with Reflectivity

C# + HLSL 
// C# - Create a reflective sphere
spheres[0] = new Sphere()
{
    position = new Vector3(0, 1, 5),
    radius = 1.0f,
    albedo = new Vector3(0.8f, 0.1f, 0.1f),    // Red base color
    specular = new Vector3(0.9f, 0.9f, 0.9f)     // Highly reflective
};

// HLSL - The specular field now controls reflectivity
// specular = (0,0,0) means fully diffuse (no reflection)
// specular = (1,1,1) means fully reflective (mirror)
// specular = (0.5,0.5,0.5) means 50% reflective

🎯 Critical: The Epsilon Offset

Notice hit.position + hit.normal * 0.001f? This tiny offset prevents the reflected ray from immediately intersecting the same surface it just hit (called "self-intersection" or "shadow acne"). Without this, you'd see black speckles on reflective surfaces.

🧮 The Math Deep Dive

Why recursion depth matters

Each bounce adds computation. In a scene with two mirrors facing each other, rays could bounce infinitely. We limit this with MAX_BOUNCES:

🔍 Bounce Count Trade-offs

• 1 bounce: Direct lighting only (Milestone 3)
• 2 bounces: Single reflections visible
• 4 bounces: Reflections of reflections (good quality)
• 8+ bounces: Diminishing returns, much slower

The Fresnel Effect (Advanced)

Real surfaces are more reflective at grazing angles. This is why a lake reflects the sky at the horizon but shows the bottom when you look straight down.

Fresnel ≈ reflectivity + (1 - reflectivity) × (1 - cos(θ))⁵
where θ = angle between view direction and normal

For simplicity, we skip Fresnel in this milestone, but it's essential for realistic glass and water.

✅ Verification

You should see:

  • The sphere reflects the ground plane
  • The sphere reflects the sky gradient
  • Moving the camera updates reflections in real-time
  • The red albedo tints the reflection slightly
  • No black speckles or artifacts on the sphere surface

🐛 Common Bug

If reflections look "inverted" or wrong, check your Reflect function. A common mistake is D + 2(D·N)N instead of D - 2(D·N)N. The sign matters — it controls whether the ray reflects away from or through the surface.

📚 What You Learned

🎓 Key Takeaways

• Reflection vector: R = D - 2(D·N)N
• Vector decomposition: split into parallel/perpendicular components
• Recursive tracing simulates light bouncing between surfaces
• Epsilon offset prevents self-intersection artifacts
• Specular color controls reflectivity per surface
• Blend local shading with reflected color based on material
