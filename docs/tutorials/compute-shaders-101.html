Compute Shaders 101

Learn GPU compute programming from absolute zero — starting with "Hello World" and building up to understanding our ray tracer.

🤔 What IS a Compute Shader?

🎬 Analogy: The Factory Assembly Line

Imagine a factory that paints toy cars:

CPU (Normal C# code): One worker paints one car at a time. 1000 cars = 1000 sequential steps.

GPU (Compute Shader): 1000 workers each paint one car simultaneously. Done in one step!

A compute shader is a program that runs on your graphics card (GPU) instead of your processor (CPU). The GPU has thousands of tiny cores that can all work at the same time — perfect for doing the same calculation on millions of pixels.

💡 When to Use Compute Shaders

• Processing every pixel on screen (image effects, ray tracing)
• Particle simulations (thousands of particles)
• Physics calculations (cloth, fluid)
• Machine learning inference
• Any problem where you do the SAME thing many times

📐 Key Concepts

1. Threads, Thread Groups, and Kernels

Kernel = The function that runs on the GPU
Thread = One instance of that function
Thread Group = A bundle of threads (e.g., 8×8 = 64 threads)

🎬 Analogy: Painting a Wall

• Kernel = "Paint this square blue" (the instruction)
• Thread = One painter painting one square
• Thread Group = A team of 64 painters working on one section
• Dispatch = Telling all teams to start painting

2. The Dispatch Call

In C#, you "dispatch" the compute shader:

C#
// Dispatch 10 groups of 64 threads each = 640 total threads
computeShader.Dispatch(kernelIndex, 10, 1, 1);

// For a 1920x1080 screen with 8x8 thread groups:
// GroupsX = ceil(1920 / 8) = 240
// GroupsY = ceil(1080 / 8) = 135
// Total threads = 240 * 135 * 64 = 2,073,600 (one per pixel!)

3. How Each Thread Knows Which Pixel to Process

HLSL
[numthreads(8, 8, 1)]
void Main(uint3 id : SV_DispatchThreadID)
{
    // id.x = which column (0 to screen width)
    // id.y = which row (0 to screen height)
    // id.z = which slice (usually 0 for 2D images)
    
    // This thread handles pixel (id.x, id.y)
    Result[id.xy] = float4(1, 0, 0, 1);  // Red pixel!
}

🔍 The Magic of SV_DispatchThreadID

This is a special "system value" that Unity automatically fills in. Every thread gets a unique (x,y,z) ID. For a 2D image, we only care about x and y — they directly map to pixel coordinates!

🚀 Tutorial 1: "Hello World" Compute Shader

Let's create the simplest possible compute shader — one that fills the screen with a color gradient.

Step 1: Create the Compute Shader

  1. In Unity, right-click Project window → Create → Shader → Compute Shader
  2. Name it "HelloWorldCompute"
  3. Double-click to open and replace ALL content with:
HLSL (HelloWorldCompute.compute)
// Declare the kernel name - REQUIRED
#pragma kernel HelloWorld

// Output texture - the GPU writes pixel colors here
// "RW" means Read-Write (we can read AND write)
// "float4" = RGBA (4 channels, each is a float)
RWTexture2D<float4> Result;

// The kernel function - this runs once per thread
// [numthreads(8,8,1)] means each group has 8x8 threads
[numthreads(8, 8, 1)]
void HelloWorld(uint3 id : SV_DispatchThreadID)
{
    // Get the texture dimensions
    uint width, height;
    Result.GetDimensions(width, height);
    
    // Convert pixel ID to UV coordinates [0, 1]
    float2 uv = float2(id.x / (float)width, id.y / (float)height);
    
    // Create a gradient: red on left, green on bottom
    float3 color = float3(uv.x, uv.y, 0.5);
    
    // Write the color to the output texture
    // id.xy = (x, y) pixel coordinate
    Result[id.xy] = float4(color, 1.0);
}

Step 2: Create the C# Controller

  1. Right-click Project window → Create → C# Script
  2. Name it "HelloWorldController"
  3. Double-click to open and replace ALL content:
C# (HelloWorldController.cs)
using UnityEngine;

public class HelloWorldController : MonoBehaviour
{
    // Drag your compute shader here in the Inspector
    public ComputeShader helloWorldShader;
    
    // Where we'll store the GPU output
    private RenderTexture target;
    
    // The kernel index (we'll look it up by name)
    private int kernelIndex = -1;

    void Start()
    {
        // Find the kernel by name (must match #pragma kernel)
        kernelIndex = helloWorldShader.FindKernel("HelloWorld");
        
        if (kernelIndex < 0)
        {
            Debug.LogError("Kernel not found!");
            return;
        }
        
        Debug.Log($"Found kernel at index {kernelIndex}");
    }

    void OnRenderImage(RenderTexture source, RenderTexture destination)
    {
        // Create the output texture if it doesn't exist
        if (target == null)
        {
            target = new RenderTexture(256, 256, 0);
            target.enableRandomWrite = true;  // REQUIRED for compute shaders!
            target.Create();
        }
        
        // Tell the shader to write to 'target'
        helloWorldShader.SetTexture(kernelIndex, "Result", target);
        
        // Dispatch!
        // 256x256 pixels / 8x8 threads per group = 32x32 groups
        helloWorldShader.Dispatch(kernelIndex, 32, 32, 1);
        
        // Copy result to screen
        Graphics.Blit(target, destination);
    }
    
    void OnDestroy()
    {
        // Clean up
        if (target != null) target.Release();
    }
}

Step 3: Set Up in Unity

  1. Create an empty GameObject: GameObject → Create Empty, name it "HelloWorld"
  2. Drag HelloWorldController script onto it
  3. In the Inspector, drag HelloWorldCompute into the "Hello World Shader" slot
  4. Press Play — you should see a colorful gradient!

🎯 What You Just Learned

• #pragma kernel declares an entry point
• RWTexture2D is how GPU writes to images
• SV_DispatchThreadID gives each thread its pixel coordinate
• Dispatch() launches all threads
• enableRandomWrite = true is REQUIRED

🚀 Tutorial 2: Passing Data from C# to GPU

Now let's send data from C# to the shader — like mouse position or a time value.

HLSL
#pragma kernel AnimatedGradient

RWTexture2D<float4> Result;

// Variables sent from C#
float _Time;        // Current time
float2 _MousePos;   // Mouse position [0,1]

[numthreads(8, 8, 1)]
void AnimatedGradient(uint3 id : SV_DispatchThreadID)
{
    uint width, height;
    Result.GetDimensions(width, height);
    float2 uv = float2(id.x / (float)width, id.y / (float)height);
    
    // Animate colors over time
    float r = sin(uv.x * 10 + _Time) * 0.5 + 0.5;
    float g = sin(uv.y * 10 + _Time * 1.5) * 0.5 + 0.5;
    float b = sin((uv.x + uv.y) * 5 + _Time * 0.5) * 0.5 + 0.5;
    
    // Mouse interaction: draw circle at mouse position
    float dist = length(uv - _MousePos);
    if (dist < 0.05)
    {
        r = 1; g = 1; b = 1;  // White circle at mouse
    }
    
    Result[id.xy] = float4(r, g, b, 1);
}
C#
void OnRenderImage(RenderTexture source, RenderTexture destination)
{
    // Send data to shader BEFORE dispatching
    helloWorldShader.SetFloat("_Time", Time.time);
    
    // Get mouse position in [0,1] range
    Vector2 mousePos = Input.mousePosition;
    mousePos.x /= Screen.width;
    mousePos.y /= Screen.height;
    helloWorldShader.SetVector("_MousePos", new Vector4(mousePos.x, mousePos.y, 0, 0));
    
    // ... dispatch as before ...
}

🚀 Tutorial 3: Structured Buffers (Sending Arrays)

For complex data like spheres, particles, or mesh vertices, use StructuredBuffers:

HLSL
struct Particle
{
    float3 position;
    float3 velocity;
    float life;
};

// A buffer of particles - like an array on the GPU
StructuredBuffer<Particle> _Particles;
int _ParticleCount;
C#
// Create a buffer that holds 1000 particles, each 28 bytes
ComputeBuffer particleBuffer = new ComputeBuffer(1000, 28);

// Fill it with data
Particle[] particles = new Particle[1000];
// ... fill the array ...
particleBuffer.SetData(particles);

// Send to shader
shader.SetBuffer(kernelIndex, "_Particles", particleBuffer);
shader.SetInt("_ParticleCount", particles.Length);

// CRITICAL: Release when done to prevent memory leak!
particleBuffer.Release();

⚠️ Memory Leak Warning

ComputeBuffers allocate GPU memory. If you don't call .Release(), that memory stays allocated forever. Always release buffers in OnDestroy() or when recreating them.

🔑 The Complete Pipeline (Summary)

📋 Step-by-Step Compute Shader Flow

1. C# Setup: Find kernel, create buffers, set data
2. C# Per Frame: Update uniforms (time, matrices, etc.)
3. C# Dispatch: Tell GPU to run X×Y×Z thread groups
4. GPU Execution: Thousands of threads run in parallel
5. GPU Output: Threads write to textures/buffers
6. C# Read: Blit texture to screen, or read buffer data

📚 Common HLSL vs C# Differences

Comparison
| Concept        | HLSL (GPU)              | C# (CPU)              |
|----------------|-------------------------|-----------------------|
| Vector access  | v.x, v.y, v.z, v.w     | v.x, v.y, v.z         |
| Color access   | c.r, c.g, c.b, c.a     | Not available         |
| Swizzling      | pos.xyz, color.rgb     | Not available         |
| Length         | length(v)              | v.magnitude           |
| Normalize      | normalize(v)           | v.normalized          |
| Dot product    | dot(a, b)              | Vector3.Dot(a, b)     |
| Lerp           | lerp(a, b, t)          | Mathf.Lerp(a, b, t)   |
| Clamp          | clamp(x, 0, 1)         | Mathf.Clamp(x, 0, 1)  |
| Sqrt           | sqrt(x)                | Mathf.Sqrt(x)         |
| Infinity       | 1.#INF                 | float.PositiveInfinity|
