Milestone 3 — Lambertian Shading

Let There Be Light

Transform a flat circle into a fully shaded 3D sphere using surface normals and the dot product.

🎯 What You'll Build

A sphere that looks truly 3D — with bright areas where light hits directly, gradual shadows on the sides, and dark areas facing away from the light. This is the foundation of all realistic rendering.

Solid white — no depth perception

After (Shaded)

Smooth gradient — looks round and 3D

📐 Core Concepts

1. What is a Surface Normal?

A normal vector is a unit-length vector that points perpendicular (at 90°) to a surface. It tells us which way the surface is "facing."

N = normalize(hitPosition - sphereCenter)

💡 Intuition

Imagine a hedgehog curled into a ball. Every spine points straight out from the center — those are the normal vectors. On a flat floor, all normals point straight up. On a sphere, they radiate outward in all directions.

2. The Dot Product

The dot product is the single most important operation in shading. It tells us how much two vectors "agree" in direction.

a · b = |a| |b| cos(θ)

When both vectors are normalized (length = 1), this simplifies to:

a · b = cos(θ)

🔍 What the Dot Product Tells Us

• 1.0: Vectors point exactly the same way (0° angle)
• 0.0: Vectors are perpendicular (90° angle)
• -1.0: Vectors point opposite ways (180° angle)
• Negative: Surface faces away from light (in shadow)

3. Lambert's Cosine Law

In 1760, Johann Heinrich Lambert discovered that the brightness of a diffuse surface is proportional to the cosine of the angle between the surface normal and the light direction.

intensity = max(0, N · L)

Where:

  • N = Surface normal (unit vector)
  • L = Light direction (unit vector, pointing FROM surface TO light)
  • max(0, ...) = Clamp negative values to zero (no negative light)

🎯 Why max(0, ...)?

Surfaces facing away from light can't receive negative light — they just get zero. The max(0, ...) ensures we don't subtract light from the scene.

4. The Full Shading Equation

For a simple diffuse material:

color = albedo × lightColor × max(0, N · L)

Where albedo is the base color of the surface (like paint color).

💻 Implementation

HLSL Shading Function

HLSL 
// Light direction - pointing TOWARD the light source
// In a real scene, this would come from a light struct
float3 _DirectionalLight = normalize(float3(1, 1, -1));
float3 _LightColor = float3(1, 1, 1);  // White light

// Shade a hit point with Lambertian (diffuse) lighting
float3 Shade(RayHit hit)
{
    // Surface normal (already normalized from intersection)
    float3 N = hit.normal;
    
    // Light direction: from hit point toward light
    // For a directional light, this is the same everywhere
    float3 L = -_DirectionalLight;  // Negate because _DirectionalLight points away from light
    
    // Lambertian term: dot product clamped to [0, 1]
    float NdotL = max(0.0f, dot(N, L));
    
    // Diffuse color = albedo * light * lambertian
    float3 diffuse = hit.albedo * _LightColor * NdotL;
    
    // Ambient term: base light that exists even in shadow
    // Without this, the dark side would be pure black
    float3 ambient = hit.albedo * 0.1f;
    
    return diffuse + ambient;
}

// Updated TraceRay that returns shaded color
float3 TraceRay(Ray ray)
{
    RayHit hit = CreateRayHit();
    
    // Test all spheres
    for (int i = 0; i < _SphereCount; i++)
    {
        IntersectSphere(ray, _Spheres[i], hit);
    }
    
    // If we hit something, shade it
    if (hit.distance < 1.#INF)
    {
        return Shade(hit);
    }
    
    // Miss - return sky color (simple gradient)
    return float3(0.0f, 0.0f, 0.0f);  // Black void
}

Visualizing the Math Step by Step

  1. Find the hit point: Using the ray equation r(t) = origin + t·direction, we know exactly where on the sphere surface the ray landed.
  2. Compute the normal: The normal at any point on a sphere points from the center to that point.
    N = normalize(hit.position - sphere.position)
  3. Get light direction: For a directional light, this is constant. For a point light, it would be normalize(lightPos - hit.position).
  4. Compute dot product: This gives us the cosine of the angle between normal and light.
    NdotL = dot(N, L)
  5. Clamp and multiply: Negative values become 0 (shadow), positive values scale the color.
    color = albedo × max(0, NdotL)

Adding a Ground Plane (Optional but Recommended)

To better see the shading, add an infinite ground plane at y = 0:

HLSL 
// Intersect ray with ground plane (y = 0)
void IntersectGroundPlane(Ray ray, inout RayHit bestHit)
{
    // Plane equation: y = 0, or dot(ray.direction, (0,1,0))
    // Solve: origin.y + t * direction.y = 0
    // Therefore: t = -origin.y / direction.y
    
    float t = -ray.origin.y / ray.direction.y;
    
    // Only count hits in front of camera and closer than current best
    if (t > 0.0f && t < bestHit.distance)
    {
        bestHit.distance = t;
        bestHit.position = ray.origin + t * ray.direction;
        bestHit.normal = float3(0.0f, 1.0f, 0.0f);  // Plane normal points up
        bestHit.albedo = float3(0.5f, 0.5f, 0.5f);   // Gray ground
        bestHit.specular = float3(0.0f, 0.0f, 0.0f);
    }
}

🎯 Key Insight

The ground plane intersection is much simpler than sphere intersection because the plane equation is linear (not quadratic). Notice how we check t > 0 — this prevents counting hits behind the camera.

🧮 The Math Deep Dive

Why does the dot product give cosine?

Geometrically, the dot product projects one vector onto another. When vectors are perpendicular, the projection has zero length. When they align, the projection is full length.

📐 Visual Proof

Imagine shining a flashlight at a wall:

• Straight on (0°): Maximum brightness (cos(0°) = 1)
• At 45°: About 70% brightness (cos(45°) ≈ 0.707)
• Grazing (90°): Zero brightness (cos(90°) = 0)
• Behind (180°): Still zero (clamped to 0)

Why add ambient light?

Real-world scenes have indirect light bouncing everywhere. Without ambient light, the shadow side of objects would be pitch black — which looks unnatural. A small ambient term (10% of albedo) simulates this global illumination cheaply.

finalColor = diffuse + ambient
finalColor = albedo × light × max(0, N·L) + albedo × 0.1

✅ Verification

You should see:

  • A sphere with smooth light-to-dark gradient
  • The brightest point faces the light direction
  • The opposite side is dark but not pure black (ambient)
  • The ground plane shows the same shading logic
  • Moving the camera preserves correct lighting

🐛 Common Bug

If your sphere has a sharp line dividing light and dark (instead of smooth), check that your normals are normalized. An unnormalized normal will make the dot product scaling wrong. Always call normalize() on normals!

📚 What You Learned

🎓 Key Takeaways

• Surface normals point perpendicular to surfaces
• Dot product measures alignment between two vectors
• Lambert's cosine law: brightness ∝ cos(angle between N and L)
• max(0, dot(N, L)) clamps negative light to zero
• Ambient light prevents completely black shadows
• Plane intersection is simpler than sphere (linear vs quadratic)
